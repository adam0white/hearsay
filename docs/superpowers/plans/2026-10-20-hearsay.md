# Hearsay Implementation Plan

> **For agentic workers:** execute the approved design in bounded tasks. Adam authorized implementation and delegation.

**Goal:** Build the locally reviewable Hearsay fortnight, replay, and playtest tools.

**Architecture:** A pure deterministic HF simulation owns minds and host consequences. Canvas and DOM render only witnessed events. IndexedDB preserves a stopped clock; exports replay logged inputs.

**Tech Stack:** TypeScript, HF 2.9.0, Vite, Vitest, Biome, Canvas 2D, Warren lab client.

**Spec:** `docs/design.md`.

## Global Constraints

- Mirror Warren setup; exact dependency pins and lab tarball.
- No edits to human-framework; no push, repository creation, or deployment.
- Seeded RNG only in sim. Inputs retain their applied minute.
- Run `npm run check` before every signed commit. Include the requested coauthor trailer.
- Deployment, public listings, and Adam's acceptance are outside this local build; dated Deferred entries preserve the design's completion contract.

## Review Focus

- Export corruption must leave the current run intact; import proves fingerprint equality.
- Reload must preserve the exact state and clock; no wall-clock catch-up.
- Play cannot reveal unwitnessed provenance or internal trust numbers.
- All six verbs need visible truthful answers; line exhaustion cannot repeat a daily stock line.
- A 360×780 phone must show usable actions without scrolling.
