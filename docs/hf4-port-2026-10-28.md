In that evidence directory, with `/opt/homebrew/bin` first on PATH:

```sh

node --input-type=module <<'JS'
import assert from 'node:assert/strict';

assert.equal(proof.ok, true);
assert.equal(proof.value.verified, true);
assert.equal(proof.value.fullHash, archive.hashes.full);

assert.equal(restored.ok, true);
const before = JSON.stringify(exportRun(restored.value));
const result = step(restored.value, {until: 86400000, inputs: []});
assert.deepEqual(result, {ok: false, error: {
  code: 'invalid-admission', path: '$.runtime', message: 'Effect was already applied'
}});
assert.equal(JSON.stringify(exportRun(restored.value)), before);
console.log({engine: archive.engine, hash: archive.hashes.full, result});
JS
```

Runtime validation, restore and exact historical replay succeed; advancing that restored history to its first midnight fails. There are no new host inputs in the failing call. The accepted archive and refusal are enough to reproduce the engine problem without executing Hearsay's bridge. The exact internal cause has not been established.
